# BSIT Portfolio: setup

1. Open `index.html` in a browser. No install or build step is needed.
2. Edit `js/data.js`. Replace every `[bracketed]` placeholder with your real details. Never add anything you have not done.
3. Add files: `assets/resume.pdf` (your resume), `assets/profile.jpg` (then set it in the avatar in index.html), and certificate or screenshot images (set their paths in data.js).
4. Skills: delete the ones you do not have and set each `l` value (0 to 100) honestly.
5. Publish free: upload the folder to a GitHub repository, then Settings > Pages > deploy from the main branch.

The contact form opens the visitor's email app. To receive messages directly, connect Formspree, EmailJS or your own backend.
